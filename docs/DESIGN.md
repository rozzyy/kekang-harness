## Brand & Style

This design system establishes a high-density, developer-native control surface built for deep technical orchestration. It balances the austere precision of low-level terminal interfaces with the fluid ergonomics of modern workflow power-tools like Linear, Raycast, and Zed.

The visual language communicates structural discipline, instant responsiveness, and zero distraction:
- **Aesthetic Movement:** Technical Minimalism crossed with Terminal-Informed Utility. Surfaces avoid gratuitous skeuomorphism or loud decorative gradients in favor of razor-thin structural dividers, dark matte layers, and precise telemetry indicators.
- **Tone & Atmosphere:** Calm, commanding, introspective. The interface behaves like high-spec optical glass placed over complex computing processes—letting codebase telemetry, prompt pipelines, and agent states lead visually.
- **Micro-accents:** Restrained purple glows demarcate active agent execution pipelines, while terminal-grade monospaced tokens surface deterministic system states (tokens, memory allocations, git hashes).

## Colors

The palette is tuned specifically for low-light sustained desktop operation, relying on strict contrast deltas between dark neutral tiers:

### Surfaces & Structural Backgrounds
- **Canvas Base (`#0A0A0B`):** Global viewport grounding, un-elevated application chrome, canvas backdrop.
- **Surface Elevation 1 (`#131316`):** Left/right utility rails, secondary workspaces, header panels.
- **Surface Elevation 2 (`#1C1C21`):** Floating inspector panels, interactive cards, active terminal panes, input surfaces.

### Borders & Dividing Rulers
- **Border Muted (`#26262D`):** Internal cell divisions, passive gutters, non-interactive bounding boxes.
- **Border Regular (`#2E2E36`):** Active card containers, input field perimeters, structural panel splitters.
- **Border Highlight (`#3F3F46`):** Hovered surfaces and focused containers.

### Typography Hierarchy
- **Text Primary (`#E4E4E7`):** Direct headings, active code snippets, active tabs, crucial telemetry labels.
- **Text Secondary (`#A1A1AA`):** Body context, active execution traces, inactive tab labels.
- **Text Tertiary (`#71717A`):** Keybindings, passive metadata, line numbers, path directories.

### Functional Status & Orchestration Signals
- **Accent Interactive (`#7C3AED` / Hover: `#8B5CF6`):** Claude Code orchestration states, primary triggers, execution loops.
- **System Success (`#10B981`):** Passing test runners, verified deployments, healthy harnesses.
- **System Warning (`#F59E0B`):** Memory limits, slow response times, rate-limit thresholds.
- **System Error (`#EF4444`):** Syntax exceptions, broken build jobs, failed agent actions.
- **System Info (`#3B82F6`):** Stream telemetry, transport notifications, active sockets.

### Domain & Semantic Markers
- **Workspace Identity:** Personal (`#10B981`), Work (`#3B82F6`).
- **Tech Stack Badges:** Laravel (`#FF2D20`), NestJS (`#E0234E`), Next.js (`#FFFFFF`), TypeScript (`#3178C6`), PHP (`#777BB4`), Python (`#3776AB`).

## Typography

Typography prioritizes high information density, structural hierarchy, and legible code metrics at micro sizes:

- **Primary Interface Font:** `Inter` handles standard interface controls, labels, and paragraph readouts. Body base sits compactly at 14px to preserve vertical real estate across multi-pane layouts.
- **Monospaced Utility Font:** `JetBrains Mono` governs file trees, terminal streams, token consumption metrics, status badges, diffs, and keyboard shortcuts (`label-kbd`).
- **Scale Rules:** Headings are deliberately restrained (max 20px on desktop); application weight is expressed through contrast, density, and modular arrangements rather than oversized display typography.

## Layout & Spacing

Designed strictly around desktop viewports with a 3-tier dockable multi-column shell:

- **Structural Grid:** 3-column split interface consisting of:
  - Fixed Collapsible Workspace Rail (`260px`)
  - Fluid Primary Orchestration Pane (dynamic flex-fill)
  - Contextual Inspector / Terminal Stream Pane (`340px` - `480px`)
- **Spacing Rhythm:** Based on a strict 4px grid rhythm. Standard internal container padding uses `space-12` (`12px`) or `space-16` (`16px`). Micro toolbars and compact list rows employ `space-6` (`6px`) vertical padding to pack dense metrics into limited vertical dimensions.
- **Layout Behavior:** Seamless panel-to-panel gutters (`1px` border dividers instead of wide empty alleys). Panels are edge-to-edge, maximizing code context and terminal visibility.

## Elevation & Depth

Visual hierarchy does not use diffuse, cloudy dropshadows. Instead, elevation relies on tonal contrast, hair-thin mechanical borders, and localized status glows:

1. **Surface Elevation:**
   - **Ground:** `#0A0A0B` (Canvas underlay)
   - **Mid (Level 1):** `#131316` (Panels, Nav, Shells)
   - **High (Level 2):** `#1C1C21` (Dialogs, Popovers, Cards, Command Palettes)
2. **Structural Borders:** Surfaces are isolated via `1px solid #2E2E36` borders. Inset dividers inside dense tables and lists drop to `#26262D`.
3. **Accent Glows:** Interactive or autonomous Claude agent activity receives a soft radial halo: `0 0 12px -2px rgba(124, 58, 237, 0.35)` to signal background generation or compilation without obscuring surrounding rows.
4. **Command Overlay:** Modal overlays utilize a subtle backdrop-filter blur (`8px`) combined with `#000000B3` to elevate focused agent actions while muting peripheral monitors.

## Shapes

The interface uses tight, precision-engineered radiuses matching modern desktop development tools:

- **Base Radius (`rounded-sm` - 6px):** Standard interactive elements: buttons, input fields, badge pills, tree item hovers, menu popovers, and keyboard tags.
- **Card / Panel Radius (`rounded-md` - 8px):** Detached telemetry cards, inspector sub-blocks, prompt run history items, and context menus.
- **Shell / Modal Radius (`rounded-lg` - 12px):** Global command palettes (Raycast-style), primary system modal windows, and detached terminal pop-outs.

## Components

### Buttons & Actions
- **Primary:** Background `#7C3AED`, hover `#8B5CF6`, text `#FFFFFF`, border `1px solid rgba(255, 255, 255, 0.1)`, height `28px` (compact) or `32px` (standard), padding `0 12px`, radius `6px`. Text weight 500.
- **Secondary / Ghost:** Background `transparent`, hover `#1C1C21`, text `#E4E4E7`, border `1px solid #2E2E36`, radius `6px`.
- **Keyboard Shortcut Accents:** Inline `<kbd>` badges nested inside buttons are styled with `#131316`, border `#26262D`, font `JetBrains Mono` at `11px`, text `#71717A`.

### Inputs & Command Fields
- **Background:** `#1C1C21`, border `1px solid #2E2E36`, text `#E4E4E7`, placeholder `#71717A`.
- **Focus State:** Border changes to `#7C3AED` with a sharp focus ring: `0 0 0 1px #7C3AED`.
- **Prompt Run Box:** Full-width multiline input with an embedded status bar at the bottom displaying active branch, context token count, and Claude model select.

### Chips & Semantic Badges
- **Stack & Context Chips:** Height `20px`, padding `0 6px`, font `JetBrains Mono` `11px`, border `1px solid #26262D`, background `#131316`.
- **Tech Stack Dot:** Includes a `6px` circular swatch keyed to the respective language color (e.g., `#3178C6` for TypeScript).
- **Workspace Pill:** Shows `Pribadi` (`#10B981`) or `Kantor` (`#3B82F6`) with an ultra-subtle tinted border and low-opacity pill background (e.g., `rgba(16, 185, 129, 0.12)`).

### Lists & Tree Views
- **Density:** Item row height `26px` to `28px`, indent `12px` per directory hierarchy.
- **Hover/Selected:** Hover `#131316`, Active/Selected `#1C1C21` with a `2px` vertical indicator bar along the left edge colored in `#7C3AED`.
- **Iconography:** Lucide icons rendered at `14px` x `14px` with a strict `1.5px` stroke width in `#A1A1AA`.

### Cards & Telemetry Blocks
- **Container:** Background `#1C1C21`, border `1px solid #26262D`, padding `12px`.
- **Header:** Row layout with font `Inter 13px Medium` and trailing `JetBrains Mono` status readouts (e.g., latency, token count, agent iteration index).

### Developer Harness Components
- **Agent Prompt Status Stream:** Card surface with left accent border: `#7C3AED` (Thinking/Generating), `#10B981` (Completed), `#EF4444` (Runtime Error).
- **Code Snippets & Diffs:** JetBrains Mono 12px, line-height 18px, background `#0F0F12`, border `1px solid #26262D`. Green diff additions use `rgba(16, 185, 129, 0.15)`, red diff removals use `rgba(239, 68, 68, 0.15)`.
